Read this honestly

  • It changes about 8 times a year. That is roughly once a quarter — this is a position-sizing dial, not a trading signal. If you find yourself checking it daily for action, you are using it wrong.
  • A first version whipsawed badly. Without smoothing, a dead band and a cooldown it changed 24 times a year and reversed 72% of the time. The current settings cut that to 3% without costing return — the fix was free, which is the only reason to trust it.
  • It will not dodge a fast crash. The gate reacts to a confirmed break of the 50-day, so a one-week collapse hits the core in full. The core is the price of catching the best days, which cluster in exactly those weeks.
  • The core is a policy choice, not a signal. At 40% it never goes lower no matter how bad things look. If you cannot hold that through a 25% index drawdown, lower it before you need to.
